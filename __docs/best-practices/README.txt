BEST PRACTICES
==============

How to apply the house conventions, with examples at the leaves.

  conventions/   Naming, ownership and the shape of these README files.
  css/           Structure, grid layout and atom skin.
  data/          Guarding records and preserving supplied values.
  handlers/      Inheriting, defaulting and wiring shared handlers.

The sibling ../house-keys/ explains the agreed vocabulary. Binding UI rules
live in ../../ganglion/coding/css/oocss/RULES.txt; these guides explain them.
