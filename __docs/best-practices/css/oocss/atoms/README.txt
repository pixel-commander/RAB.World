ATOM SKIN
=========

Atoms provide reusable skin without owning component structure or layout.
Stack their classes in markup; remove a class to remove that skin.

  action/      Action surfaces and their interaction states; action-* classes.
  container/   Container surfaces, borders and depth; container-* classes.
  effects/     Effect skin; effect-* classes (the folder name is plural).

Preserve the complete family prefix. Use shared tokens and the atom's own
custom properties for instance overrides. Each leaf explains its boundary.
