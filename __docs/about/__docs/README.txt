__docs
======

PURPOSE
__docs is where the documentation files for RAB.World will live. This is
the user's definition of the folder.

WHAT IT SUPPORTS
RAB.World is the new home for the AI-human interaction project and the
baseline for work toward self-similarity. Its documentation will explain
house keys, naming conventions, code styles, Box interface testing and
training materials developed from LLM code reviews.

The about area explains the responsibilities of the house's parts and
records what is currently known about them. It should help a reader
understand how Box, its toolkits and the ganglion relate to one another.

DOCUMENTATION AND TRAINING
Useful review-based teaching material carries the relevant source,
applicable rule, review finding, reasoning, example or correction, and
verification evidence. An LLM's finding is a claim to check; it does not
become an established rule merely because it appeared in a review.

The task's existing house instructions require preserving original records
and quotations, distinguishing user statements from assistant interpretation,
and separating observed facts from hypotheses. Those principles apply when
turning reviews into explanations and lessons.

RELATION TO THE GANGLION
The ganglion is intended to hold the central skills required to produce
acceptable code. Documentation explains the project and the use of those
skills. Describing a proposed skill or workflow here does not mean that it
has already been implemented or adopted.

CURRENT SCOPE
The user has named __docs as the documentation home. A full documentation
layout, training format and publishing workflow have not yet been specified.
Existing documentation within Box and the toolkits remains at its current
source locations; this task did not migrate those files.

BASIS
The user's RAB.World introduction and folder definitions in this task,
together with the house instructions supplied for this task. This README
records those decisions and their implications without creating new policy.
