PURPOSE
ganglion will be the central set of skills required to complete acceptable
code in RAB.World. This is the user's stated direction for the folder.

HOW IT FITS
RAB.World is the baseline for house keys, naming conventions, code styles
and interface testing. The ganglion is the intended home for the shared
skills that guide implementation and review against those expectations.
RAB.Toolkits supplies executable tools; RAB.Box connects words to tool
execution and results. __docs explains the house and holds teaching material.

A skill can explain how to do work and how to judge its result. Its presence
does not by itself prove that a tool enforces it or that generated code
satisfies it. Verification must examine the produced output and behavior.
