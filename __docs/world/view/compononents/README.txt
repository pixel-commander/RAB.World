WORLD VIEW COMPONENTS

This folder holds human documentation for components used by the world view:
what each component shows, which records it receives, and which shared tools
its actions invoke. No component inventory has been defined here yet.

Use the same contracts as the tools and records being displayed. Components
own structure; atoms own skin. Consult the current UI rules before building.
Keep indexing and registry logic with their shared owners, not in components.

This documentation folder's existing name is compononents. It does not
define or rename a source-code components folder.
