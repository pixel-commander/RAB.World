WORLD VIEW

The view is the interface for working with a world's shared information:
finding its records, seeing indexed folders, and understanding what projects
can refer to. Records and indexing belong to their shared owners; the view
should display and invoke those capabilities rather than maintain a second
registry or scanner.

RAB.WorldView at C:\RAB.WorldView is currently a minimal React scaffold.
World browsing, beacon discovery and live index displays are intended work,
not completed features. The world itself is stored under .rab/worlds/[name].

The compononents subfolder contains documentation for view components.
