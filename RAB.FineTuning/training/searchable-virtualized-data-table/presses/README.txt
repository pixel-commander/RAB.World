PRESS RECORDS
=============
Copy press.template.json for each planned press. This is provenance, not executable
training configuration. Parameter update method (for example LoRA or full tuning)
is deliberately unselected. Model formatters own wrappers, tokens and masking.
Record immutable source/export/checkpoint identities and all relevant settings.
Use the same held-out suite and controlled inference settings before and after a
press. Save raw outputs, per-case scores, failures, regressions and reviewer decisions.
Report completed only after the actual work has executed and evidence is saved.
Keep each run separate; do not overwrite a previous comparison with a newer result.
No record here starts a model, training job, export, evaluation, or approval.
