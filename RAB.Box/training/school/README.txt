RRAABBIITT SCHOOL
=================
Training means installing/proving symbolic knowledge, not tuning a model.

Cycle:
LESSON -> COLD ATTEMPT -> EXACT VERDICT -> VERIFIED CORRECTION -> RULE -> SAME-PROBLEM RETRY -> COLD EXAM -> RETAIN ONLY IF EXACT.

Courses are executable JSON lessons. The runtime is bridge/school-runtime.mjs.
Unknown words are never stored merely as unknown. Only positive rules are eligible for durable training memory.
