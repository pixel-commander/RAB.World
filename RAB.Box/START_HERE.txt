PURPOSE
-------
v0.9.3 adds the missing construction composition layer above the verified v0.9.2
nested-seat / construction-seat foundation.

LAUNCH
------
Windows:
  RUN_UI.cmd

Any platform with Node >= 22:
  node server.mjs --open

Both launch methods use http://127.0.0.1:52814 and the current user's .rab
folder for all Box-owned saved work (Windows: %USERPROFILE%\.rab).
npm start uses the same launch path. Never save Box memory beside server.mjs.
Settings, sessions, requests, results, logs and test output belong under that
one home. Only actual project source edits belong in the selected project.
Do not delete the user's .rab: it holds projects and execution history.
If the port is busy, check the existing instance rather than starting a
second server on a random port. Explicit --port remains available.

VERIFY
------
  npm test
  npm run language:audit

Optional UI receipts:
  python tests/browser_interaction.py
