MAGIC BOX -- TYPED WORD MAP v0.1
================================

    λP.λQ.∀x(P(x) → Q(x))
    = give me two predicates; test that every P is also Q in domain D.

INPUT:
    make a component named "DatePicker" with class 'container-main'

JOBS:
    make             CREATE
    a component      new component specification
    named            fill name seat
    "DatePicker"     literal value; preserve case
    with class       fill CSS-class seat on the same specification
    'container-main' exact registry lookup; never invent class membership

OWNER IS A SEAT, NOT A PRONOUN CLASS.
I/me refer to the speaker; you refers to the addressee.
With me binds partner, not owner. We/us need explicit group binding.
