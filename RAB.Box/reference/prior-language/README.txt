PRIOR MAGIC BOX LANGUAGE MATERIAL
=================================
These files are preserved as reference material only.

They came from the earlier magic-box-lexicon-v0.2 package and encode the older
role/prefix style (verbs, field phrases, current-location phrases, boolean words).
They are NOT loaded as v0.6 execution authority.

Why keep them:
- they contain useful vocabulary and examples from the earlier exact resolver;
- they make it easy to compare old keyword/role matching with the v0.6 seat compiler;
- they can seed future regression/contrast tests without quietly changing runtime.

v0.6 active language lives in language/type-mapper.json plus the grammar/order logic
in bridge/seat-parser.mjs. Operator-reviewed additions live in
language/user/type-overrides.json.
