GLOSSARY OF TERMS — THE BOX
===========================

Term      | Meaning in the Box
----------|---------------------------------------------------------------------
Project   | The workspace being worked on: root folder, settings, saved records.
Session   | A saved conversation/work context within that project.
Turn      | One submitted message or answer.
Group     | A related set of steps, reviewed/executed together. Some UI wording
          | already calls this an action.
Step      | One planned operation, with its selected tool, inputs, missing
          | information, and status.
Execution | An actual attempt to run a tool. A step is the plan; execution is
          | doing it.
Receipt   | The recorded outcome and references to results.
Seat / bag| A seat is a named input/context value; the bag carries those values
          | between steps.
