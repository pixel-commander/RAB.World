Review Code Grids
Uses the parent's executor with meta.group=grids. Inputs and result shape are
the shared code-review contract. Calls audit/code-review/grid-continuity through
the shared scratch runner helper. JSX/TSX only; optional css resolves class-based
layout. Ordinary leaf Flex is allowed; the existing Grid-Flex-Grid rule remains.
See ../README.txt for storage and limitations.
