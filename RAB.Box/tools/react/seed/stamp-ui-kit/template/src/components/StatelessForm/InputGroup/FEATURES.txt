InputGroup is the field shell: label (+ required mark), the control, then hint and error. Every
   other field in the package wears it rather than restating that stack, which is why an error
   line looks identical under a dropdown and under a date picker.

   With no children it IS a text field — a bare InputGroup is the text case, not a separate
   TextInput beside it. description is the hint; error is the failure sentence.
