MODULE RESPONSIBILITIES
========================
core.mjs     Value merging, explicit failures, finite every(), path checks.
schema.mjs   House metadata, options object/array normalization, field validation.
project.mjs  Fresh PATHS/settings/assets, declared catalogs, dependency definitions.
language.mjs Full-consumption bounded grammar, declared aliases, slot attachments.
runtime.mjs  Pending request/answers, dependency returns, preflight and execution.
mutation-plan.mjs     Create-only file plans and byte verification.
worker.mjs   Trusted Node settings/stamp protocol in a fresh process.

Explanations live here and in docs/, not inside executable source.
No module infers a capability from the title/description alone.
No model-provided path chooses a script.
No runtime treats an unobserved resource as definitely absent.
No request executes unless the host enables writes and authorizes every frame.

Settings are still the source of required/optional fields. The parser reads
those fields; it does not maintain a second hardcoded React input contract.
