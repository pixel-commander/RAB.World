Style Guide
===========
Theme is the default group. Surfaces, borders, typography and spacing use shared theme tokens.
Atoms discovers manifest/v1 category indexes at src/atoms/*/manifest.json. Valid manifests supply category tabs; their entries supply the demos. Unlisted files do not create entries. Missing demos display an explicit message.
URLs: /style-guide/theme/surfaces and /style-guide/atoms/containers.
This is included with the kit; settings.paths is intentionally omitted.
